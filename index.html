Kurir Nebula

Antar paket cahaya melintasi tiga sektor galaksi. Kumpulkan kristal, hindari asteroid, lalu terbang ke portal emas. Kendali: WASD / tombol panah untuk terbang, F untuk menembak (di layar sentuh pakai tombol Tembak), P untuk jeda, M untuk musik. Tembak musuh untuk mendapat kristal. Nyawa maksimal 5.
